# pocket-mbti

12문제에 답하면 내 MBTI와 성향이 닮은 포켓몬을 알려 주는 재미용 테스트예요.

- 바로 하기: https://2juwon.github.io/pocket-mbti/ (Settings → Pages에서 `main` / `root`를 켜면 열려요)

## 어떻게 동작하나요

- E/I, S/N, T/F, J/P 네 가지 성향마다 3문제씩, 모두 12문제라 동점이 나오지 않아요.
- 결과 카드: 도감 번호, 분류, 속성, 한 줄 소개, 설명, 강점, 찰떡 궁합, 성향별 비율 막대
- 결과 공개 연출: '두구두구' → 카드 등장 + 속성 색 배경과 아이콘 + 색종이
- '공식 도감에서 진짜 ○○ 보기' 버튼으로 포켓몬 공식 사이트 도감(영어)을 새 창으로 열어요.
- 결과 문구 복사, 16가지 결과 전체 보기

## 고치는 법

`index.html` 한 파일이에요. 외부 라이브러리 없이 동작하고, 아래 데이터만 바꾸면 돼요.

- `Q`: 질문과 선택지 (선택지마다 해당 성향 글자)
- `R`: MBTI별 포켓몬 이름, 도감 번호, 속성, 소개 문구, 찰떡 궁합
- `SLUG`: 공식 도감 주소에 쓰는 영어 이름
- `ICON`: 속성 아이콘(직접 그린 SVG)
